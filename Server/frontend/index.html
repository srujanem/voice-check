Paste this into your frontend code to connect to the backend:

const API_KEY = "YOUR_API_KEY"; async function detectImage(file) { const formData = new FormData(); formData.append("file", file); const response = await fetch("http://localhost:8000/api/image/detect", { method: "POST", headers: { "X-API-Key": API_KEY }, body: formData }); return await response.json(); }

Training on RTX 4050

The ML training scripts are specifically optimized for your 6GB VRAM constraint. They utilize Mixed Precision (fp16) and frozen backbone layers to ensure you don't run out of memory.

Please double-click the .bat files in your Server folder to execute the training process directly in your terminal where you can monitor epoch progress!
