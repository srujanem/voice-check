The symbol for pounds (£) or dollars ($) is called a currency symbol, and it is used to represent a specific type of money. The symbol is placed in front of the number to indicate the value of the amount being discussed. For example, if you see the symbol £ in front of a number, it means that the number represents a value in pounds. 
When we say the amount out loud, we usually say the number first, followed by the name of the currency. For example, if you see the amount £10, you would say "ten pounds." This is because we usually say numbers before other words, just like we say a person's name before their last name. 
So, the reason we use the currency symbol before the number and say the number before the currency name is just a convention, or a way that we have agreed to do things. It helps to make it clear what we are talking about and makes it easier for everyone to understand.
