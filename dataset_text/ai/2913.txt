An Internet Protocol (IP) address is a unique numerical label assigned to each device (e.g., computer, printer) connected to a computer network that uses the Internet Protocol for communication. An IP address serves two main functions: host or network interface identification and location addressing. A subnet, or subnetwork, is a smaller network that is created within a larger network. It is a way of dividing a larger network into smaller, more manageable chunks. For example, if a company has a large network with many computers, it might create several smaller subnets to better organize and manage the network. Network routing is the process of moving data from one place to another on a network. When you send an email, for example, your computer sends the message to a router, which is a device that helps direct the message to its final destination.
