Yes, it is possible to make videos using code. In fact, this is how many computer graphics and special effects in movies are created. 
To make a video using code, you would first need to have a way to represent the visual elements that you want to include in the video. This might include things like 3D models of objects, characters, and environments, as well as textures, lighting, and other visual effects. 
Once you have these elements, you can use a computer program to "render" the video by combining all of these elements together and generating a sequence of still images, or frames, that make up the video. These frames can then be played back in sequence at a high frame rate (e.g., 30 or 60 frames per second) to create the illusion of motion. 
So, to make a video using code, you would need to have a good understanding of computer graphics and programming, and be able to use specialized software to create and render the video. It can be a complex and time-consuming process, but it allows for a lot of creativity and control in creating the final product.
