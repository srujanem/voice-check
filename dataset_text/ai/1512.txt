A class is a template for creating objects. It defines the characteristics and behaviors that an object of that class will have. For example, you might have a class called "Dog" that has characteristics like breed and age, and behaviors like barking and fetching. 
An object is an instance of a class. For example, if you have a class called "Dog", you could create an object called "Fido" that is a specific dog with its own breed, age, and behaviors. Fido would be an object of the "Dog" class. 
A method is a behavior that an object can perform. For example, if you have a class called "Dog" with a method called "bark", then any object of the "Dog" class, like Fido, would be able to bark.
