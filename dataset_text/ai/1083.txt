Websites can detect if you have AdBlock running by including some code in their website that checks for the presence of certain files or scripts that are associated with AdBlock. This code is usually executed when the website is loaded in your web browser. 
The way that the website checks for AdBlock can be different depending on the type of ad that is being displayed. For example, a website might check for AdBlock before showing a banner ad by looking for a specific file or script that is associated with AdBlock. On the other hand, a website might check for AdBlock before showing an ad before a YouTube video by looking for a different file or script. 
Overall, the website is able to detect AdBlock by looking for specific files or scripts that are associated with the AdBlock software. If it finds these files or scripts, it knows that AdBlock is running and can either block the ad from being shown or show a different ad that is not blocked by AdBlock.
