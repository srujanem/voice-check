Emulating a computer or video game console like the SNES is difficult for a few reasons: The hardware of the original device is different from the hardware of the device running the emulator. The emulator has to recreate the behavior of the original hardware as closely as possible, which can be challenging. The software that ran on the original hardware (e.g. the SNES games) was written to take advantage of the specific features and limitations of that hardware. The emulator has to recreate all of these features and limitations in order to run the software correctly. The original hardware had specific performance characteristics (e.g. how fast it could process instructions, how quickly it could access memory) that the emulator has to match. If the emulator is too slow or too fast, the software may not run correctly. There can be a lot of subtle details and quirks in the original hardware that are hard to recreate accurately. These can be hard to discover and can take a long time to get right. Overall, emulating a computer or video game console is a complex task that requires a lot of attention to detail and a deep understanding of how the original hardware and software worked.
