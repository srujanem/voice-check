They are called "floating-point" because the decimal point can "float" around to represent different numbers.\n\nOne way to think about floating-point numbers is to imagine them like a set of building blocks. Each block represents a certain value, and you can stack them up to make different numbers. It would be like trying to make 0.2 using only blocks that represent 1, 0.5, and 0.25. It's not going to be exactly 0.2, but we can get pretty close.\n\nIn this case, if we use 0.1 blocks to try to make 0.2, we get 0.199999999999999996.
