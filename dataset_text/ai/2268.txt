An array is like a list of items, where each item has a number (called an "index") so you can find it again. For example, you might have an array of numbers where the first number is 3, the second number is 7, and the third number is 9. You can find these numbers by their index, like this: array[0] is 3, array[1] is 7, array[2] is 9, A 2D array is like a grid, where each item has two indices (a row and a column). For example, you might have a 2D array of numbers that looks like this: 3 7 9, 4 5 6, 1 2 8, In this 2D array, you can find the number 5 by its indices: array[1][1] is 5. A 3D array is like a cube of items, where each item has three indices (a row, a column, and a depth). For example, you might have a 3D array of numbers that looks like this: 3 7 9, 4 5 6, 1 2 8, 9 1 8, 7 4 2, 3 6 5, A 4D array is like a stack of cubes, where each item has four indices (a row, a column, a depth, and a time). For example, you might have a 4D array of numbers that looks like this: 3 7 9 9 1 8, 4 5 6 7 4 2, 1 2 8 3 6 5, 9 1 8 3 7 9, 7 4 2 4 5 6, 3 6 5 1 2 8, It can be hard to imagine what a 4D array would look like, but think of it like a bunch of cubes stacked on top of each other, where each cube has its own row, column, and depth. You can find an item in a 4D array by using its four indices: array[x][y][z][t] is the item at position (x, y, z, t) in the array.
