Magnetic engines, also known as magnetic motors, are devices that use magnetism to generate rotational force or torque. While it is possible to build devices that use magnets to produce rotational force, it is not currently possible to build a perpetual motion machine using magnets alone. Perpetual motion machines are devices that can operate indefinitely without any external energy input. Such machines violate the laws of thermodynamics, which state that energy cannot be created or destroyed, only converted from one form to another. Therefore, it is impossible to build a machine that can operate indefinitely without any energy input. In order for a magnetic motor to work, it would need some external energy source to power it. For example, a magnet could be used to generate rotational force by using electricity to create a magnetic field. However, the electricity used to power the magnet would eventually run out, and the magnet would stop working. In summary, while it is possible to use magnets to generate rotational force, it is not currently possible to build a perpetual motion machine using magnets alone.
