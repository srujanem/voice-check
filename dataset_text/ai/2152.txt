The first computer programs were written in machine code, which is a series of instructions that can be directly executed by a computer's central processing unit (CPU). These instructions are usually represented as numbers and are very basic, such as telling the computer to store a value in memory or to perform a calculation. In the early days of computing, programmers would write these machine code instructions by hand, using a series of switches and buttons on the computer itself. This was very time-consuming and prone to errors, so it wasn't long before people started looking for a better way to write programs. One solution was to use assembly language, which is a programming language that is closer to human language and is easier for programmers to read and write. Assembly language is still very low-level and is specific to a particular type of computer, but it is much easier to use than machine code. As computers became more powerful and complex, it became increasingly difficult to write programs using assembly language. This led to the development of higher-level programming languages, such as C and FORTRAN, which are closer to human language and are more abstract than machine code or assembly language. Compilers are programs that translate code written in a high-level programming language into machine code that can be executed by a computer.
