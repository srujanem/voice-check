Many games have a "press any button to continue" message before the main menu loads because it gives the player a chance to get ready to play the game. When you start a game, it takes a little bit of time for the game to load all of the necessary data and get everything set up. The "press any button to continue" message lets the player know that the game is ready to start and gives them a chance to get their hands on the controller so they can start playing as soon as the main menu appears. It's like a countdown to the start of the game, giving the player a chance to get ready and be prepared to start playing.
