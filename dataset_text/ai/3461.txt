When a computer or smartphone deletes a file, it doesn't actually remove the data from the device right away. Instead, it simply marks the space that the file was using as being available for use again. This means that the data is still there, but the computer or smartphone treats it as if it's not. Think of it like this: imagine you have a really big piece of paper and you draw a picture on it. When you're done with the picture, you can erase it by rubbing out the lines you drew with an eraser. The paper is still there, but now you can draw something else on it because the space is empty again. It's the same idea with deleting a file on a computer or smartphone. The data is still there, but the space it was using is empty and ready to be used again. Eventually, when the computer or smartphone needs to use the space that the deleted file was using for something else, it will overwrite the data from the deleted file with the new data.
