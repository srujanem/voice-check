Console games are often developed on high-end PCs, but they are still designed to be played on specific gaming consoles, such as the Xbox One or the PlayStation 4. While it is possible to port a game from one console to another, or from a console to a PC, it can be a complex and time-consuming process. Developers have to make sure that the game will work properly on the new platform, and that it will take advantage of the unique features and capabilities of that platform. This can involve making significant changes to the game's code and graphics, as well as adapting the controls and user interface to work with different input devices. In some cases, developers may choose not to port a game to a new platform because it would be too difficult or expensive to do so. In other cases, the game may simply be more popular on one platform than another, and it may not be worth the effort to port it. Overall, the availability of ports can vary widely depending on the game and the platforms involved, so it's always a good idea to check with the developer or publisher to see if a particular game is available on the platform you want to play it on.
