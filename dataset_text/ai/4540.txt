"I'm not a robot" CAPTCHAs are used to help websites tell whether a user is a real person or a computer program trying to access the site. They do this by showing a checkbox that says "I'm not a robot" and sometimes also showing some images and asking the user to select all the images that match a certain description.\n\nA computer program or script might be able to click the checkbox, but it wouldn't be able to correctly select the images that match the description. That's because the images are usually distorted or obscured in some way, and it's difficult for a computer program to recognize what they are.\n\nSo when a real person looks at the CAPTCHA, they can easily select the correct images and click the "I'm not a robot" checkbox, but a computer program would have a much harder time doing it. This helps the website know that the user is a real person and not a computer program trying to access the site.
