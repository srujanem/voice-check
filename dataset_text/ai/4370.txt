Great question! An irrational number is a number that cannot be written as a simple fraction, like 3/4 or 5/7. Instead, it goes on forever as a decimal without repeating in a pattern. For example, the number pi is an irrational number because it goes on forever as 3.14159265358979323846264338327950288419716939937510... and it never repeats the same pattern of digits.\n\nWe know that pi is an irrational number because mathematicians have studied it and found that it does not repeat in a pattern. They have also come up with ways to calculate pi to more and more decimal places, and every time they do, the digits continue on without repeating.\n\nI hope that helps explain it a little bit!
