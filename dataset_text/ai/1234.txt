When a hard drive is formatted, some of the space on the drive is reserved for the file system and other system files. This means that the drive will appear to have less total capacity than it actually does. 
For example, if you have a 750 GB hard drive, the actual capacity of the drive is 750 billion bytes. However, when the drive is formatted, some of that space is set aside for the file system and other system files, so it may appear that only 700 GB are available for use. 
This is a normal part of how hard drives and file systems work, and it is necessary in order to ensure that the drive can function properly and efficiently. The amount of space that is reserved for the file system and other system files will depend on the size of the drive and the type of file system being used.
