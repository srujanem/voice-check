The saying "the exception proves the rule" means that if there is an exception to a rule, it actually helps to confirm or prove that the rule exists. Here's an example to help clarify: Imagine there is a rule that says all birds can fly. However, there is an exception to this rule - penguins can't fly. The fact that there is an exception to the rule (penguins can't fly) actually helps to prove that the rule exists (all birds can fly).
