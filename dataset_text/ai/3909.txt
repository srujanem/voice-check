These instructions are called "code." The code tells the computer what to do and how to do it. For example, the code might tell the computer to show a character on the screen or to make that character move. To create the graphics for a game, the programmer uses a special program called a "graphics engine." This program helps the computer create the images and animations that you see on the screen. The graphics engine uses code to tell the computer how to draw the images and how to make them move. So, in short, video game programming is the process of writing code to tell the computer what to do and how to do it. This code is used to create the graphics, characters, and actions that you see in the game.
