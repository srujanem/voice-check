Some people try to make this into a Windows vs * nix debate , but in all honesty even * nix systems require restarts for certain type of updates . Simply put , it 's related to how computers work and how modern OSes ( Windows , * nix variants work fundamentally the same way in this regard ) execute programs . They load the program into memory when it starts , and it does n't reload it after it is running ( and is really hard to do safely ) . This means that when updates change the programs , the running programs do not know about the changes and keep on going . There are exceptions and it all has to do with how the program was written to execute . Stuff like images or fonts can be re - read while the program is running so they can apply changes on the fly . Other stuff that change the logic in the program itself can not be as easily reloaded . Generally speaking I will restart machines that are running critical apps after updates , regardless of what OS they are running ( Windows or Linux variants ) . Why ? Because it 's the safest route to ensure everything is running up to date versions . Take Linux for example . A lot of times a program will used a shared object or have a persistent service running using a particular command . If these components are updated and the related processes / services are not restarted , they will not have the changes applied . If these are critical security fixes , then there 's a high chance that a vulnerable version is running even if you 've patched it . Windows tends to err on the side of caution on this regard .
