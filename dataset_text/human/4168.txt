Think of it as the weirdest kind of addition you 've ever done . Typically , binary is done out to the 8th digit . This allows you to handle a number between 0 and 255 . To take a binary number ( which looks like 00111100 in binary ) and convert it to a decimal number , consider each digit ( each 1 or 0 ) as a decimal value that must be added to determine the final decimal number . If the first digit is a 1 , then add 128 . If the second digit is a 1 , then add 64 .
