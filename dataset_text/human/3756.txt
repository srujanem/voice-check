To go deeper than the " game engine does it for you " level of other answers : Say you want to put the letter A on the screen . We will say the game engine call looks like this : put_letter_on_screen("A " ) The game engine implements it like this : if $ platform is xbox360 then do print_letter("A " ) if $ platform is ps3 then do draw_character("A " ) $ platform is a placeholder for an actual value . What the game developers then do is change the placeholder like this $ platform = xbox360 and build the code This all happens automatically and is supported by the game engine itself so all they have to do is click a button and it builds everything .
