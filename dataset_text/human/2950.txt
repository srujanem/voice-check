Unsure which platform you are talking about ; however I will answer the question for Windows , and assume you are talking about deleting the application folder , not just the icon on the desktop . As others have mentioned already , when you install an application , it creates a bunch of files in a bunch of places ; generally , the actual executable applications get placed in its own folder in the " Program Files " directory . However , most applications on Windows do ' extra ' interesting things , such as entering a license key ( in the registry ) , setting it up so that the application starts up when the computer starts ( start - up hook ) , setting up a background service to check for updates ( windows service ) , adding a shortcut in the right click menu ( shell hook ) , and potentially installing drivers . Basically , all of these ' extra ' things have to go into specific areas defined by Microsoft , and they do not sit within the actual program folder . So , when ' uninstalling ' an application , the uninstaller will remove all of these other things that simply deleting the application will not do . Therefore , assuming you trust the application , you should uninstall it instead of deleting it . ( if you do n't trust the application , i.e. its malware , that answer is not always true )
