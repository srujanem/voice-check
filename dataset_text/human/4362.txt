A class is a place where you put a bunch of related things together in a program . For example , a Point has an x coordinate and a y coordinate . A Rectangle consists of a Point that is its location , a length and a width . The Rectangle class also defines certain behavior- it can calculate its own area and perimeter , and given another rectangle , it can check to see if the two Rectangles intersect . Because Rectangle is a class , it means I can create many different Rectangles that all know how to do those things . In code , this would look like ( assuming Java class syntax ): class Point { public int x ; public int y ; } class Rectangle { public Point location ; public int width ; public int height ; public int area ( ) { return length * width ; } public int perimeter ( ) { return 2 * length + 2 * width ; } public boolean intersects(Rectangle other ) { / * implementation left as exercise to the reader * / return false ; }
