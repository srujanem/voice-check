The capacity of 750 Gb is listed as if it all was directly accessible , thereby giving you 805,306,368,000 bytes ( a byte is the smallest single piece of information that represents a usable character ) . But it is not that simple . All hard drives have their built in controller , which uses a small amount of the hard drive space to keep an index of the files on the drive . All operating systems have some sort of index of the files on the hard drive , on the hard drive itself , thereby using up some more of the free space . And the hard drive space is not used up very well , by default . Most operating systems will start writing a file in the next empty spot , even if the file is bigger than that location . It then breaks the file up and continues writing it in the next empty spot , and repeat until the file is written . Every break in the file is the same as having to write another file , as far as the info needed to keep track of all the parts of the file , which uses up more space that is now not available to the user . Then , files themselves are not always exactly the size of the smallest allowed data chunk . So if a file is 4352 Megabytes and the minimum data size is 1024 Kilobytes , then that extra 256 Kilobytes takes up a partial 1024 Kilobytes and the rest of it is unavailable for writing , thereby reducing available space even more . TL;DR Hard drives and operating systems use hard drive space for their own purposes and your data gets written to the drive in a way that wastes space .
