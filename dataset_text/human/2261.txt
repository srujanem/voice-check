Think of dimension as something that can be measured . A cube has ( 1 ) length , ( 2 ) width , and ( 3 ) height . So it has 3 dimensions . A plane has ( 1 ) length , and ( 2 ) width . So it has 2 dimensions . A line has ( 1 ) length . So it has 1 dimension . A point has none of the above . So it has 0 dimensions .
