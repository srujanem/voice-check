Most programs do n't start up everything the moment you start them . Take a browser for instance , to have a nice and fast start up sequence , it does n't load up all of the engines , but when you load a page that requires one of these engines , the browser will load it up . Most of the time , these engines wo n't unload incase you load another page that requires it . The longer you have these programs open , the more of these things will load so it actually becomes slower . Another reason for programs slowing down is just because of mistakes in the code that slow a program down . Everytime a piece of code gets run with one of these mistakes l , the program slows down . These mistakes can even be found in an OS . Restarting a program or computer helps unload these , thus making it faster again .
